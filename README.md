# What's this?
This is a 4-stereo-channel audio mixer I made circa 2018. It's simple design is based on NE5532 opamps.

# What's in it?
The repo contains the KICAD project files for the mixer. I've updated it for KICAD 7.0 (my currently installed version), but I have lost the custom footprints I made at the time. Still, the PCB file is sufficient to reproduce the board.
